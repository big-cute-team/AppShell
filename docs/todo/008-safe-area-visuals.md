# 008. 세이프 에어리어·상태바 시각 정리

**상태: 🟡 배포 전 처리** — 첫 Android 실기기 테스트(2026-08-04)에서 발견.
기능 문제는 아니지만 스토어 스크린샷을 찍기 전(004~005 사이)에 정리해야 합니다.

## 증상

실기기에서 화면 위아래에 공백이 보입니다.

- 맨 위(상태바)와 맨 아래(내비 버튼) 띠가 **흰색** — 웹이 다크 테마라 도드라짐
- 상태바 아래(PLick 로고 위)와 하단 탭바 아래에 **검은 여백**

## 원인 (확인된 것 / 추정)

- 흰 띠 — 셸의 `SafeAreaView edges={['top','bottom']}` 인셋이
  `BACKGROUND_COLOR`(`#FFFFFF`)로 칠해짐. 확실함.
- 검은 여백 — 웹 페이지 자체 패딩으로 추정. **셸이 아니라 웹 콘텐츠 안쪽**임.

## 해야 할 일

- [ ] 같은 페이지를 폰 크롬에서 열어 검은 여백이 똑같이 있는지 비교
      — 크롬에도 있으면 **웹 저장소 소관**으로 넘기고, 여기서는 아래 색 맞추기만 처리
- [ ] `src/config.ts`의 `BACKGROUND_COLOR`를 웹 다크 배경색으로 교체
      (웹 쪽에 정확한 색 값 확인 — `#000000`인지 브랜드 다크 색인지)
- [ ] `WebShell.tsx`의 `<StatusBar style="dark" />`를 `light`로
      — 배경이 어두워지면 아이콘도 밝은 색이어야 보입니다
- [ ] 시뮬레이터/실기기에서 재확인 (스플래시 → 웹 전환 시 배경색 어긋남 없는지 포함)

## 다음 판단 (필요해지면)

- 웹뷰를 상태바 밑까지 확장(`edges={['bottom']}` 등)하고 웹이 인셋을 직접 처리하는 방식
  — 몰입감은 좋지만 **웹 쪽 대응이 필수**라 색 맞추기로 부족할 때만 검토.
  003 문서의 "발견되면 처리할 것"에 적어 둔 방법입니다.

## 참고

- 웹 테마가 라이트/다크 전환을 지원한다면 `BACKGROUND_COLOR` 하나로는 부족해질 수
  있습니다. 그때는 웹 → 앱 메시지(`postMessage`)로 배경색을 맞추는 방법을 검토.
