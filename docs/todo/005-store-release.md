## 공통

- [ ] 두 스토어의 앱 이름/설명/스크린샷을 일치시키기
- [ ] 개인정보처리방침 페이지가 모바일 웹에 실제로 존재하는지 확인
- [ ] 계정 삭제 경로 — 회원가입이 있는 앱은 **양쪽 스토어 모두 필수**입니다.
      웹에 계정 삭제 기능이 없다면 먼저 만들어야 합니다
- [x] 댓글 신고·차단 기능 (**웹 저장소에서 구현 완료**, 2026-08-26) — iOS 1차 심사의
      정보 요청이 "UGC 신고·차단 시연"을 요구해 웹에 구현: 댓글 신고(스팸/욕설/
      괴롭힘/음란/기타 사유 선택), 사용자 차단(차단한 사용자 댓글 숨김 + MY의
      차단 목록에서 해제). Google Play UGC 정책과 Apple 1.2 요건 충족.
      Play 콘텐츠 등급 설문은 "없음"으로 답했던 상태였고, 신고·차단 구현을 반영해
      설문 현행화 완료 (2026-09-01 이전에 갱신했다고 확인됨)
